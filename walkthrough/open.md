# Open a JSON file in the viewer

The viewer never replaces the normal text editor. Open a `.json`, `.jsonc`, `.json5`, `.geojson`, `.har`, `.ipynb` or `.webmanifest` file and click the tree icon in the editor title, or right-click the file in the Explorer and pick "Open in JSON Viewer".

To view JSON that is not in a file, select it in any editor (or copy it) and run "JSON Viewer: Open Selection or Clipboard in JSON Viewer".
